# Images pour la documentation

Ce répertoire contient les images utilisées dans les articles de documentation.

## Diagrammes Mermaid (générés)

- `diagramme-architecture-globale.png` : Architecture Client / Frontend / Backend / PostgreSQL
- `diagramme-modeles-donnees.png` : Modèle entité-relation User, Project, Simulation
- `diagramme-deploiement.png` : Architecture de déploiement (Nginx, Frontend, Backend, PostgreSQL)
- `diagramme-algorithmes.png` : Chaîne des algorithmes (Monte Carlo, Cholesky, capitalisation, optimisation, taxes)

Voir [DIAGRAMMES.md](../DIAGRAMMES.md) pour la liste complète et la régénération.

## Captures d'écran (optionnel)

- `longview-parametrage.png` (ou `.jpg`, `.jpeg`) : Capture d'écran de l'interface de paramétrage complète
- `longview-simulation.png` (ou `.jpg`, `.jpeg`) : Capture d'écran du graphique de simulation avec les percentiles 10, 50, 90%

## Format recommandé

- Format : PNG ou JPEG
- Résolution : Minimum 1200px de largeur pour une bonne qualité d'affichage
- Taille : Optimiser les images pour le web (compression raisonnable)
